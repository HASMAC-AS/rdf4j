## Evidence motivating the adapter

Stored serializer profile summaries contain exclusive exact top-stack witnesses of redundant QueryBindingSet hash operations through QueryEvaluator.addResult → TupleResultBuilder.result → WorkbenchPageResultWriter.handleSolution:

- base: no such stack in retained top40; absence is NOT zero work.
- depth:6 get samples +5 put samples,11/898 Java samples.
- serializer:8 get +7 put,15/866.
- qualified stack:9 get samples,9/829; put stack absent from retained top40.

These are lower bounds from a truncated ranked-stack summary, not total adapter cost or wall-time shares. The broad binding category includes unrelated engine materialization, transport and binary writer work and must not be assigned to this adapter. Source shows addResult builds ordered values, result reconstructs a QueryBindingSet, then the page writer looks values up by name again. That bounded roundtrip is the candidate, not all binding overhead. Sampled allocation classes do not establish adapter-retained heap or exact per-row allocations.

## Prespecified protocol proposal

One balanced Latin square, four fresh servers per arm,60warmups +30measured requests:

1. base, stack, both, ordered
2. stack, ordered, base, both
3. ordered, both, stack, base
4. both, base, ordered, stack

Primary: both versus stack full POST-to-EOF latency. First-row latency is separately critical and must not be hidden by completion throughput. Also ordered/base, stack/base, both/base and paired factorial interaction. Four independent forks per arm, no adaptive extension, trimming or favorable-tail selection; report measured thirds/per-index convergence and retain all samples. Prior fixed60warmups did not guarantee convergence.

Same reconstructed actual Server→binary→Workbench Java→NDJSON→Node pipeline, full100k six-slot response on real LMDB synthetic fixture. Exact common writer/transport/memo flags and dependencies frozen. No browser rendering, concurrent QPS, cold-machine or historical8M claims. Four untimed full-term/uniqueness/checksum qualifications plus route/memo/no-spill/ledger and all three family origin witnesses before timing. Qualify actual ordered-path hits with untimed-only diagnostics/tests if origins alone do not prove the branch. Never mix tracing into timed hot paths.
