Source and toolchain
--------------------
The public dot/overlay-performance-experiments-20261117-8fc7b0 branch contains the source/tests; no separate patch is required. Original base: HASMAC-AS/rdf4j 8fc7b0137164ffdc1f5d080b943fd362931137dd. JDK25 and Maven3.9.11 were used. Experimental flags remain default-off.

Build reactor dependencies with -DskipTests -DskipITs (test jars are needed). Never use -am while running tests. Then compile the LMDB module tests and generate its dependency classpath with dependency:build-classpath and an absolute -Dmdep.outputFile pointing to experiments/overlay/classpath.txt. The scripts expect the local toolchain under ../tools and Maven repository under ../m2; adapt those paths to your installation. mvn.sh generates local proxy settings from HTTPS_PROXY; use ordinary Maven settings instead when not behind this workspace proxy.

Validation
----------
run-memo-growth-proof.sh proves real unobserved map-growth replay, fresh memo, compiled irKernel on both attempts, exact output, caller-context restoration.
run-combined-tests.sh runs the original focused combination suite.
run-broad-regression.sh [output-directory] runs compiled top-level evaluation test classes in40-class shards, preserving selections/logs/exits. Use a fresh output directory to retain prior evidence.
run-store-regression.sh runs the broader store/boundary/value/replay selection. These selections are not the whole module. Reports in copied shard directories may include stale unrelated reports; selections and log summaries are authoritative.

Fixtures and earlier experiments
-------------------------------
OverlayOptionalQueryBenchmark accepts -Doverlay.benchmark.warmups=N (default2). -Doverlay.benchmark.fixture=/new/empty/path keeps/reuses its generated dataset, refuses nonempty unmarked directories, validates groups/fanout and persisted triple count, and never deletes a configured persistent fixture. Default temporary fixtures are deleted on exit.
Earlier overlay-only scripts use their named frozen class directories. RESULTS.md distinguishes valid micro timings, initial unexercised query integration, and final scalar hit proof. Typed overlay materialization remains unrecommended/default-off. Raw JFR files are retained locally and excluded from public artifacts because they can contain environment metadata; profile-summary.txt contains sanitized findings.
